# Базовые понятия языка C#
### Создать косольные приложения на языке C#, которое реализует следующие задания:
1. Вычислить an, a и n - натуральные числа. При этом, не пользуясь никаними другими арифметическими операциями, кроме умножения.

2. В числе x, содержится более двух цифр, зачеркнули его  вторую цифру. Когда к образованному при этом числу справа приписали вторую цифру числа x, то получилось число n.

По заданному x найти число n  (значение x вводится с клавиатуры, x >= 100).

### Пример работы кода
вводим `x=121111`

получаем `n=111112`
